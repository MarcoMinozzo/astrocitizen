# D-007 — Atlas de reporte observacional

**Decisão:** manter um atlas interno (`docs/atlas/`) com fontes oficiais de registro/reporte por rede (AAVSO, MPC/ADES, TNS, BeSS, IOTA, ExoClock, COBS, WDS, …), mapeado aos PO-*.

**Uso:** base dos exporters EXP-* e validação RN-080.

**Manutenção:** revalidar links/specs antes de cada implementação de exporter.
