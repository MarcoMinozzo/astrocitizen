Interface Standards

The ASCOM Interface Standards are published online and in PDF form as the ASCOM Master Interfaces (Alpaca and COM). This is our master implementation- and platform-neutral ASCOM interface specifications for Platform 7, with FAQ enhancements. This is the definitive reference for the various device interface (patterns) and the detailed functions/methods and variables/properties. These abstract definitions apply to both ASCOM Alpaca and ASCOM COM. (PDF Version for offline use)
